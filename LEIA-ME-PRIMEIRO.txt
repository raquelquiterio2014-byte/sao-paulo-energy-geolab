Sao Paulo Energy GeoLab

1. Extraia o ZIP inteiro para uma pasta, por exemplo D:\sao-paulo-energy-geolab.
2. Instale Python 3.11 ou 3.12, incluindo o launcher do Windows.
3. Execute INSTALL.bat uma vez e espere concluir.
4. Execute TEST.bat para testar.
5. Execute START.bat e mantenha a janela aberta.
6. Abra http://127.0.0.1:8001 no navegador.

A interface está em inglês. Os dados incluídos são SINTÉTICOS.
Não são o cadastro oficial de usinas nem a malha real completa.
A importação aceita GeoJSON no formato documentado em README.md.
Versão 1.1: importações e histórico agora ficam salvos em SQLite.
O sistema reabre o último conjunto após atualizar a página ou reiniciar.
Use Saved datasets para reabrir importações e Saved analysis history para resultados.
O banco é criado em data\energy_geolab.sqlite3. Não apague essa pasta ao atualizar.
Para backup, pare o servidor e copie o arquivo do banco para outro local.
Ao mudar de pasta, copie também a pasta data para manter os dados.
Os cálculos não confirmam conexões elétricas.
O mapa depende de internet para carregar a biblioteca e o mapa-base.

Caso ocorra um erro, mantenha o terminal aberto e copie a mensagem completa.
